# Character Library / 角色库

## Purpose / 目的

This file stores reusable character descriptions. The Script Agent selects characters, and the Storyboard Agent injects their descriptions into each relevant shot.

此文件保存可复用角色描述。剧本 Agent 选择角色，分镜 Agent 将角色描述注入相关镜头。

## Character Template / 角色模板

```text
id:
name:
age_range:
visual_identity:
clothing:
personality:
movement_style:
voice_or_dialogue_style:
negative_prompt:
```

## Example Characters / 示例角色

```text
id: hero
name: The Hero
age_range: 25-35
visual_identity: determined face, athletic build, expressive eyes
clothing: dark practical jacket, worn boots, minimal accessories
personality: brave, focused, emotionally restrained
movement_style: fast, precise, alert
voice_or_dialogue_style: short direct sentences
negative_prompt: distorted face, extra limbs, inconsistent outfit
```
